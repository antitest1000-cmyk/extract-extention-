⚡ Comprehensive Toolkit

10 Powerful Extraction Engines in One Free Extension

OmniExtract replaces fragmented browser tools, scrapers, and python scripts with a unified command deck. Everything executes 100% locally in your browser sandbox without sending a single byte to external servers.

🖼️ 1. Deep Image Harvester + Custom Multi-Selection

Interactive Selection Staggered Downloads High-Res & Dimension Filters

Extract every visual asset embedded in any webpage, including <img> tags, srcset high-density variations, lazy-loaded data-src attributes, <picture> elements, and CSS background-image URLs.

  • Interactive Checkboxes: Select images manually with individual checkboxes or Ctrl/Shift + Click to download only what you need.
  • Selective Download: Click ⬇ Download Selected (X) to save only chosen images without flooding your downloads folder with unwanted graphics.
  • Selective Copying: Copy URLs of only your selected items directly to your clipboard.
  • Dimension Filters: Instantly filter between All, High-Res (>1000px), Icons (<120px), JPG, PNG, WebP, and SVG.
  • Lightbox Viewer: Zoom in on any image with resolution badges and quick single-file download.

📊 2. HTML Table to CSV, JSON & Markdown Converter

1-Click CSV GitHub Markdown Clean JSON Grid

Automatically scans the webpage for structured data tables, benchmark grids, pricing tables, and spreadsheets.

  • Parses table headers (<th>) and row entries (<tr>/<td>) into structured relational datasets.
  • Export to CSV: Clean comma-separated spreadsheets ready for Microsoft Excel, Google Sheets, or Python Pandas.
  • Export to Markdown: Formats tables directly into GitHub-flavored Markdown for technical documentation or LLM context.
  • Inspect in Page: Highlights the corresponding table on the active webpage with a luminous indicator.

📇 3. B2B Leads & Contacts Dossier

Filtered Emails Phone Numbers 12+ Social Channels Form Actions

Instant intelligence dossier for sales prospecting, security auditing, and competitive research.

  • Verified Email Extraction: Filters email addresses against .png, .js, and .css false positives.
  • Phone Extraction: Detects international and domestic phone numbers via tel: protocol and regex patterns.
  • Social Network Harvester: Catalogs profiles from LinkedIn, Twitter/X, GitHub, Discord, Telegram, WhatsApp, YouTube, and Instagram.
  • HTML Form Endpoints: Catalogs form action URLs, submission methods (POST/GET), and field schemas.

🤖 4. AI & LLM Clean Markdown Exporter

ChatGPT / Claude Ready Zero Token Waste Ad Stripping

Transform noisy, ad-cluttered webpages into pristine Markdown context for ChatGPT, Claude, and Gemini.

  • Strips navigation headers, sidebar widgets, cookie banners, tracking scripts, and footer links.
  • Preserves clean heading hierarchy (H1-H6), blockquotes, lists, and formatted text.
  • Calculates estimated token counts so you know the exact context budget before pasting into AI models.
  • 1-Click Copy for AI or download as a standalone .md file.

🗂️ 5. Structured Cards & Feeds Extractor

Exact Visual Order Product Listings Article Previews

Extract repeating visual entities—like e-commerce catalog items, blog post cards, and directory listings—with all related fields kept together.

  • Captures Title, Image, Description, Price, Badge, and Link in exact DOM order.
  • Copy entire cards in 1-click or export the full catalog as a structured JSON array or CSV.
  • Click Inspect to scroll and highlight the card on the live webpage.

🎯 6. Visual Point & Pick Element Harvester

Interactive Crosshair CSS Path Generator

A visual point-and-click scraping mode inspired by browser devtools inspection tools.

  • Click the crosshair button in the header or Overview Quick Actions deck.
  • Hover over any element to view its HTML tag, class list, and bounding dimensions.
  • Click to harvest text, nested images, links, outer HTML, and CSS selector directly to your clipboard.

⚡ 7. Single Page Application (SPA) State Inspector

Next.js __NEXT_DATA__ Nuxt __NUXT_DATA__ Shopify Analytics

Bypasses noisy HTML parsing by retrieving raw backend JSON state payloads embedded in modern web frameworks.

  • Next.js: Extracts <script id="__NEXT_DATA__"> containing full server-side props and product datasets.
  • Nuxt.js: Extracts hydration state arrays from __NUXT_DATA__.
  • Shopify: Accesses raw product catalog objects from window.Shopify.
  • 1-Click Copy Raw JSON and Download state.json.

🛡️ 8. Security & Leaked Credentials Scanner

Bug Bounty Ready AWS / GCP / Stripe Keys

Proactively scans page scripts, inline configuration objects, and environment bundles for accidentally exposed secrets.

  • Detects AWS Access Keys (AKIA...), Google Cloud / Firebase API keys (AIza...), GitHub PATs, Stripe keys, and JWT bearer tokens.
  • Categorized by severity (CRITICAL, WARNING) in the Cloud & APIs tab.
  • 1-Click copy of detected tokens for devsecops audits and remediation.

📈 9. Interactive SEO Health Scorecard (0–100)

Technical Audit OpenGraph Preview

Real-time technical SEO evaluation of the active webpage with an actionable checklist.

  • Audits Title tag length (ideal: 30–60 chars) and Meta Description presence (ideal: 120–160 chars).
  • Validates canonical link tag, OpenGraph tags (title, image, description), and H1 structure.
  • Displays an interactive visual social preview card.

🗺️ 10. XML Sitemap & Multi-Page Crawler Engine

Recursive Index Parser CDATA & Namespace Safe Multi-Page Spider

Discover and harvest whole website architectures from XML sitemaps or via an in-browser crawler.

  • Probes robots.txt and standard paths (/sitemap.xml, /sitemap_index.xml).
  • Recursively traverses nested sitemap indices to extract thousands of leaf URLs.
  • Instant in-page extraction when viewing direct XML files (e.g. myinstants.com/sitemap.xml).
  • Export complete URL lists to .txt or .csv for downstream crawlers.
