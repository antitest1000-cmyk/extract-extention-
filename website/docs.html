⌨️ Keyboard Shortcuts Reference

OmniExtract features a 2-row command deck designed for rapid keyboard operation:

Shortcut Action Target View / Engine
Alt + 1 Switch to Overview & SEO Audit Tab 1: Overview
Alt + 2 Switch to Image Harvester & Gallery Tab 2: Images
Alt + 3 Switch to Video & Audio Harvester Tab 3: Media
Alt + 4 Switch to Structured Cards & Feeds Tab 4: Cards
Alt + 5 Switch to HTML Tables (CSV/JSON/MD) Tab 5: Tables
Alt + 6 Switch to B2B Leads & Contacts Tab 6: Leads
Alt + 7 Switch to Cloud Infrastructure & Secrets Tab 7: Cloud & APIs
Alt + 8 Switch to All Page Links Catalog Tab 8: Links
Alt + 9 Switch to XML Sitemap Engine Tab 9: Sitemap
Alt + 0 Switch to Multi-Page Site Crawler Tab 10: Spider
Arrow Left / Right Cycle sequentially between tabs Command Deck
Ctrl / Shift + Click Toggle image selection checkbox Images Gallery

🛡️ Architecture & Local Isolation Guarantee

Unlike commercial scrapers that route web traffic through remote proxy networks or third-party servers, OmniExtract executes exclusively within your browser's private V8 JavaScript engine.

  • No External Telemetry: OmniExtract contains zero Google Analytics, Mixpanel, Sentry, or tracking pixels.
  • No Cloud Backend: All DOM parsing, table formatting, and XML processing occur in memory on your computer.
  • Open Source Auditability: The complete unpacked extension source code is fully readable and modifiable under the MIT license.
