OmniExtract v1.0.0 — The Initial Production Release

Released on November 14, 2026 • Manifest V3 Compliant
LATEST RELEASE

OmniExtract 1.0 represents a complete, unified suite for web data harvesting, asset archiving, lead generation, and SEO analysis directly inside your Chromium browser.

✨ Key Highlights

  • Interactive Multi-Image Selection: Check individual image boxes or Ctrl/Shift + Click cards to selectively download only desired images via "⬇ Download Selected".
  • Zero-Scroll Two-Row Command Deck: 10 distinct extraction engines organized into two 5-tab rows with instant hotkeys (Alt+1 through Alt+0).
  • XML Sitemap Index Engine: Fully recursive sitemap traversal with XML namespace tolerance and CDATA block parsing.
  • SPA Backend State Inspector: Instantly grabs raw backend state from Next.js (__NEXT_DATA__), Nuxt (__NUXT_DATA__), and Shopify.
  • Security & Leaked API Keys Scanner: Proactively scans bundles for exposed AWS keys, Google API keys, Stripe tokens, and JWTs.
  • Technical SEO Health Scorecard (0–100): Dynamic audit score with interactive checks for title length, meta description, canonicals, and OpenGraph tags.
  • Visual Crosshair Point & Pick Harvester: Click anywhere on a page to extract text, HTML, and CSS selectors directly to your clipboard.
  • Full-Screen Pro Viewer: Dedicated dashboard (viewer.html) for searching and filtering large datasets.

🐛 Bug Fixes & Hardening

  • Resolved temporal dead zone initialization bug on dynamic DOM mutation scans.
  • Added strict 2.5s AbortController timeouts on robots.txt background fetches to prevent hanging on rate-limited sites.
  • Fixed Chrome XML viewer DOM quirks using namespace-agnostic element selection.

🔮 Upcoming in v1.1.0 Roadmap

  • PDF document text and table extraction engine.
  • One-click export directly to Google Sheets via OAuth.
  • Automatic pagination detection for multi-page category listings.
