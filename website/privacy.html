Privacy Policy & Data Security Pledge

OmniExtract was created with an uncompromising commitment to privacy: your web browsing, extracted records, and downloads belong to you alone. We collect zero data.

1. Information We Collect

None. OmniExtract does not collect, log, store, or transmit any personal information, browsing history, visited URLs, IP addresses, search queries, or extracted datasets.

2. How Extension Permissions Are Used

OmniExtract requests only the minimal permissions required to extract and export data from web pages:

  • activeTab: Grants temporary read access to the active webpage only when you click the extension popup icon.
  • scripting: Used to execute the content script that scans DOM elements (images, tables, media, headings).
  • storage: Used solely to save your local UI preferences (such as Grid vs. List view mode) in your browser's local sandbox.
  • downloads: Enables saving extracted datasets (CSV, JSON, Markdown, images) directly to your local computer when you click a download button.
  • <all_urls>: Necessary so you can extract data from any website of your choosing without domain restrictions.

3. Third-Party Services & Trackers

OmniExtract contains zero third-party trackers, zero Google Analytics, zero advertising SDKs, and zero external CDNs. All scripts, fonts, icons, and dependencies are bundled locally within the extension package.

4. Open Source Auditability

The complete source code of OmniExtract is publicly available on GitHub under the MIT License. You are welcome to audit, review, and fork the code at any time.
