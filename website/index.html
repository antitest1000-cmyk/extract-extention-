Step-by-Step Workflows

How to Use OmniExtract Like a Pro

Workflow #1

🖼️ How to Scrape & Batch Download Website Images

  1. Navigate to any webpage or image gallery (e.g., Unsplash, Pinterest, e-commerce shop, portfolio).
  2. Click the OmniExtract puzzle icon in your Chrome toolbar.
  3. Switch between Grid Gallery and List Table layout using the toggle button.
  4. Filter images by format: JPG, PNG, WEBP, or SVG.
  5. Click any thumbnail to inspect in the full-size Lightbox Zoom Modal, or hit "Download All" to batch save all images to your downloads folder.
Workflow #2

☁️ How to Hunt Cloud Buckets & Leaked Endpoints (Bug Bounty / Auditing)

  1. Open the target application or website.
  2. Click OmniExtract and select the Cloud & APIs tab.
  3. The engine automatically scans the DOM, external resource tags, and inline JavaScript files for:
    • AWS: S3 buckets (*.s3.amazonaws.com), CloudFront, API Gateway
    • Google Cloud: GCS buckets (storage.googleapis.com), Firebase DB, Cloud Run
    • Azure: Blob storage (*.blob.core.windows.net), Azure Edge CDN
    • Cloudflare: Workers, Pages, R2 Buckets, Supabase databases
  4. Click "Copy" to copy specific endpoints or click "Export Tab as CSV/JSON" to save the complete inventory.
Workflow #3

🗺️ How to Extract Every URL from a Website Sitemap

  1. Visit the root domain of the website you want to audit.
  2. Click the Sitemap tab inside OmniExtract.
  3. Click "Extract Sitemap". OmniExtract will automatically check robots.txt, probe standard sitemap paths, and recursively follow nested <sitemapindex> child files.
  4. Browse the extracted list with last-modified dates, priority, and change frequency.
  5. Click "Export URLs (.txt)" to download a clean text file of URLs ready for Python scripts, wget, curl, or Screaming Frog!
Workflow #4

🎬 How to Capture Audio Podcasts & Video Streams

  1. Open any article, news site, or media post.
  2. Open OmniExtract and head to the Video & Audio tab.
  3. Inspect detected HTML5 <video> and <audio> tracks, direct MP4/MP3 download links, and YouTube/Vimeo embeds.
  4. Listen to audio files directly using the embedded audio player without opening new tabs, or click "Download" to save the stream.
Workflow #5

🗂️ How to Extract Structured Cards (Title, Image & Description Combined)

  1. Open any product catalogue, news feed, or article list (e.g. Amazon, Etsy, Medium, Shopify stores).
  2. Open OmniExtract and click the Cards tab.
  3. OmniExtract automatically identifies repeating containers and binds their Title, Image, Description, Price/Badge, and Link into clean unified objects.
  4. Click "📋 Copy All" on any card to copy its full details in one click, or click "{ } JSON" to copy the card as clean code.
  5. Click "🎯 Locate" to smoothly scroll to and highlight that exact card on the live webpage!
  6. Toggle between Cards View and JSON Tree View, or export all cards to structured CSV / JSON.

Got Questions?

Frequently Asked Questions

Is OmniExtract completely free? Are there hidden fees? +

Yes, 100% free and open-source forever! There are no subscriptions, no premium tiers, no credit card requirements, and no "pro upgrades". You get the full source code and can use it as much as you want.

Why isn't OmniExtract in the official Chrome Web Store? +

Google requires all developers to pay a $5 registration fee before publishing any extension to the Chrome Web Store. Since this is an independent, non-commercial tool, we chose to host the code for free here so anyone can download the ZIP and load it in 20 seconds. It also gives you total freedom to inspect every line of code!

Is it safe? Does OmniExtract track my passwords or browsing history? +

OmniExtract is 100% safe and privacy-first. The extension runs entirely locally inside your browser sandbox. It makes zero network calls to external analytics, tracking servers, or telemetry. Your extracted data never leaves your machine.

Which browsers are supported? +

OmniExtract is built on Chrome Manifest V3 and is fully compatible with all Chromium-based browsers, including: Google Chrome, Brave Browser, Microsoft Edge, Opera, Vivaldi, and Arc.

Does it work on password-protected pages or paywalls? +

Yes! Unlike external scraping bots that get blocked by Cloudflare or login screens, OmniExtract operates inside your active tab using your authenticated browser session. If you can see the page in your browser, OmniExtract can extract it.

How do I update the extension when a new release comes out? +

Simply download the updated OmniExtract-v1.0.zip file, extract and replace the files inside your existing OmniExtract folder, open chrome://extensions, and click the circular reload arrow (🔄) on the OmniExtract card. Your extension updates instantly with all your settings preserved.

What export formats are available? +

You can export data in three standard formats:
• JSON: Complete nested data structure including dimensions, alt texts, cloud providers, and timestamps.
• CSV: Clean spreadsheet format ready for Microsoft Excel, Google Sheets, or Pandas.
• TXT: Clean list of raw URLs (one per line) ready for command-line tools like wget, curl, or custom Python scripts.

Does OmniExtract capture new images & media as I scroll infinite feeds? +

Yes, seamlessly! OmniExtract runs an intelligent in-memory accumulator and an active MutationObserver. As you scroll down dynamic feeds (like Pinterest, Instagram, Twitter/X, or e-commerce catalogues), new images and media are automatically captured in real time. Even if virtualized frameworks remove older elements from the screen DOM to save memory, OmniExtract retains them all in memory. You can also click the ⚡ Auto-Scroll button to let OmniExtract harvest the entire feed hands-free!

Can I extract title, image, description, and links together from cards or divs? +

Yes, exactly in their original hierarchy! Open the Cards tab. OmniExtract identifies repeating containers (product cards, article previews, listings) and groups their Title, Image, Description, Price/Badge, and Link into cohesive units. You can click "📋 Copy All" to grab the complete card in one click, click "🎯 Locate" to flash the container on the webpage, or export all cards as a structured JSON array or CSV!
